# Labasni iOS App
**v1.0.0** – *Application mobile Labasni*

[![Swift](https://img.shields.io/badge/Swift-5.9-orange)](https://swift.org/)
[![iOS](https://img.shields.io/badge/iOS-17.x-lightgrey)](https://developer.apple.com/ios/)
[![License](https://img.shields.io/badge/License-MIT-blue)](./LICENSE)

Application mobile iOS **Labasni** pour recommandations de style basées sur l'IA.  
Développée avec **Swift**, **SwiftUI** et **Combine**.

---

## 🚀 Fonctionnalités principales

- Affichage et mise à jour du profil utilisateur  
- Connexion / Inscription sécurisée avec JWT  
- Upload d’avatar via Cloudinary  
- Réinitialisation de mot de passe via OTP  
- Interface moderne et responsive avec SwiftUI  

---

## 🛠 Stack technique

- **Langage**       : Swift 5.9  
- **UI**            : SwiftUI  
- **Gestion état**  : Combine  
- **Backend**       : API REST Labasni (NestJS + MongoDB)  
- **Stockage images** : Cloudinary  
- **Authentification** : JWT
